## Recommended first pilot

Use the next sermon passage rather than attempting a whole-library migration.

Pilot sequence:

1. Identify 3-6 material exegetical questions.
2. Add only the most relevant commentary/article resources to Drive.
3. Build source cards for those resources.
4. Build one issue dossier for a genuinely disputed question.
5. Run SDS STANDARD_VERIFIED retrieval.
6. Verify that the EXEGETICAL_SOURCE_LEDGER points back to recoverable source locations.
7. Note retrieval failures before scaling the library.

## Scale only after the pilot

Do not bulk-ingest hundreds of files until:

- retrieval finds the right source reliably;
- source cards are cheap enough to maintain;
- passage/topic indexing is sufficient;
- source dependence is being captured;
- the SDS is not over-retrieving merely because material is available.
