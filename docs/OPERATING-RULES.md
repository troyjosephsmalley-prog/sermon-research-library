# Operating Rules

## New source

1. File the original in Google Drive.
2. Create a source card in `sources/`.
3. Record source competence and coverage.
4. Add only reusable claims with recoverable page/location references.
5. Add the source to `LIBRARY-INDEX.yaml`.

## New disputed issue

1. Create an issue dossier in `issues/`.
2. Link evidence by claim ID rather than re-copying source summaries.
3. Preserve source dependence through independence groups.
4. Preserve live alternatives.

## New sermon project

1. Identify material exegetical questions.
2. Search passage/topic indexes and source cards.
3. Reopen original Drive source locations where verification requires it.
4. Populate the SDS `EXEGETICAL_SOURCE_LEDGER`.
5. Create a project adjudication only for genuinely governing disputed questions.
6. Add reusable research back to this repository after the project.

## Promotion rule

No project adjudication becomes a general library conclusion automatically.

## Copyright rule

Do not commit source PDFs, ebooks, scans, or substantial copyrighted extracts to GitHub.
