# Sources

Store one structured source card per reusable source.

Suggested subdirectories may be added as the library grows:

- commentaries/
- lexicons-grammars/
- monographs/
- journal-articles/
- historical-cultural/
- theological/
- homiletics-communication/
- delivery-research/

Do not store the original copyrighted source file here. Keep it in the connected Drive archive and record its recoverable locator in the source card.
